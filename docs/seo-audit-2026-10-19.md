# Sendian Security SEO audit and growth plan

**Scope:** `sendiansecurity.com` live site, Astro source, and public search-result snapshot taken on 2026-10-19.

## Executive summary

SISS has strong **branded** visibility: the homepage was the first returned web result in this audit for `Sendian Security Qatar`, `sendiansecurity Qatar`, `security services Qatar Sendian`, and `SISS Qatar security services`.

It does **not** have comparable visibility for the commercial non-brand searches that match its systems-integration offer:

| Query tested | Observed public-search result |
| --- | --- |
| `security company Qatar` | No SISS result in the returned results; the query is dominated by guarding companies and a local pack. |
| `CCTV installation company Qatar` | No SISS result in the returned results. |
| `access control systems Qatar` | No SISS result in the returned results. |
| `ELV company Qatar` | No SISS result in the returned results. |
| `MOI approved CCTV company Qatar` | The SISS homepage appears in the returned results, but not as the leading result. |

This is a **public-search snapshot from Exa**, not an authoritative Google position report. Exact Google rankings, impressions, CTR, and country/device variation require verified Google Search Console access. The findings still establish a useful baseline: branded discovery works; the core, non-branded service pages need stronger intent targeting and the site has an urgent URL-migration problem.

## Highest-priority actions

1. **Restore the value of URLs already indexed.** Public search results still show old `/security/...`, `/portfolio/...`, and `/portfolios/...` URLs, but all five sampled URLs now return `404`. Add one-to-one permanent (`301`) redirects before requesting re-indexing.
2. **Choose one host.** Both `https://sendiansecurity.com/` and `https://www.sendiansecurity.com/` return `200`. Keep `https://sendiansecurity.com` as canonical and configure a server-level `301` from `www` to the non-`www` host.
3. **Retitle and rewrite service snippets.** Metadata exists, but the service-page descriptions are 306–641 characters, so Google will almost certainly truncate or rewrite them. Several article titles are 82–138 characters and descriptions are 162–248 characters.
4. **Build focused landing pages for the proven commercial intents.** Start with CCTV installation/MOI compliance, access control, and security-system AMC. Do not target generic “security company Qatar” as the primary term unless SISS actually supplies manned guarding; the current results show that intent belongs to guarding providers.
5. **Add business, service, and article structured data.** The current site has valid basic Organization and WebSite JSON-LD only on the homepage and BreadcrumbList only when a page passes breadcrumbs. It has no LocalBusiness/ProfessionalService, Service, or BlogPosting markup.

## On-page and content updates

### 1. Build the three high-intent pages first

Each page should contain a clear H1 matching the primary intent, 800–1,200 useful words, a visible enquiry CTA, and links to the relevant service, projects, and contact page:

1. **CCTV Installation in Qatar** — survey/design, MOI process where applicable, camera/VMS/storage choices, commissioning, maintenance, real project evidence, and a short FAQ.
2. **Access Control Systems in Qatar** — cards, biometrics, visitor management, doors/turnstiles, CCTV integration, commissioning, and maintenance.
3. **Security System Maintenance & AMC in Qatar** — covered systems, planned maintenance, fault response process, upgrade support, and service-area statement.

Avoid generic, repeated marketing copy and unverified “best” or “leading” claims. Include location naturally in service context, not in a list of copied city pages.

### 2. Turn projects into proof

Publish individual, consented case studies for named projects. Each should state the facility type, real security requirement, systems delivered, SISS role, compliance scope (only if verified), project date, and measurable outcome where disclosure is permitted. Link the case study to its relevant service page.

### 3. Improve trust/entity signals

On the About and Contact pages, show the legal business name, acronym (“SISS”), Doha address, phone, email, accreditation/certification evidence, and links to the official LinkedIn, Facebook, and Instagram profiles. Keep these identical to the Google Business Profile and reputable directories. Never publish approval or certification marks without current authorization.

## Structured-data plan

Generate JSON-LD from the same data shown to visitors:

1. **Homepage:** extend Organization to include `alternateName: SISS`, `description`, `sameAs` social profiles, and only verified address/phone/logo. Use `ProfessionalService`/`LocalBusiness` only after validating the appropriate type and business details.
2. **Service pages:** add a `Service` object with the exact `serviceType`, provider, and `areaServed: Qatar`. Do not add price, ratings, or availability that are not displayed and maintained.
3. **News articles:** add `BlogPosting` with `headline`, `description`, canonical URL, featured image, `datePublished`, `dateModified`, author/publisher, and publisher logo.
4. **Breadcrumbs:** pass breadcrumb data to all indexable hierarchy pages, not only news.
5. **FAQs:** add `FAQPage` only for genuine, visible question-and-answer content. Do not expect a FAQ rich result; use it for clarity and entity understanding.

Validate deployed markup in Schema Markup Validator and Google Rich Results Test. Structured data improves understanding; it does not guarantee a rich result or ranking.

## Measurement and release plan

1. **Before release:** record the 21 current sitemap URLs, titles, descriptions, canonicals, HTTP status, and redirect mappings.
2. **Deploy redirects and host canonicalization first.** Test every old URL returns a single-hop `301` to the intended new URL.
3. **Deploy metadata and focused-page content.** Rebuild with `npm run check` and `npm run build`; crawl the generated site to verify one H1, one canonical, one title, and one description per indexable page.
4. **Search Console:** verify the Domain property, submit `https://sendiansecurity.com/sitemap-index.xml`, inspect the five replacement URLs, and monitor crawl/indexing errors weekly for eight weeks.
5. **Ranking baseline:** in Search Console Performance, filter to Qatar and compare query impressions, clicks, CTR, and average position for the keyword clusters above at 28-day intervals. Treat external rank trackers as supplementary, not authoritative.
6. **Local visibility:** claim and complete the Google Business Profile only with verified business information; select an accurate category, retain consistent NAP, add genuine project photos, and request reviews without incentives or gating.
